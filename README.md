# 🎨 HTML & CSS Lab

> A personal repository dedicated to improving **HTML and CSS skills**
> through hands‑on practice and small UI projects.

------------------------------------------------------------------------

## 📚 About This Repository

This repository was created as a **learning laboratory** to experiment
with modern front‑end techniques using only **HTML and CSS**.

The goal is to strengthen core front‑end fundamentals by building small
components, layouts, and visual effects without relying on frameworks.

It focuses on:

-   Writing **clean and semantic HTML**
-   Practicing **modern CSS techniques**
-   Building **responsive layouts**
-   Creating **UI components**
-   Experimenting with **animations and visual effects**

------------------------------------------------------------------------

## 🧠 What You'll Find Here

Examples of things practiced in this repo:

-   Profile cards
-   Landing page layouts
-   UI components (buttons, cards, forms)
-   CSS animations
-   Layout experiments using Flexbox and Grid
-   Visual effects and creative CSS

------------------------------------------------------------------------

## 📂 Project Structure

The repository is organized into small independent exercises:

    web-layout-practice
    │
    ├── profile-card
    

Each project typically contains:

    index.html
    style.css

The idea is to keep projects **simple, focused, and easy to experiment
with**.
